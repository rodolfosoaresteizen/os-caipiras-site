## DESIGN E ESTILO VISUAL

### Cores Principais:
- **Verde Escuro:** #2d5016 (Cor dominante, representa a natureza/interior)
- **Laranja/Vermelho:** #d84630 (Destaque, energia, apetite - conforme logo original)
- **Branco/Creme:** #f5f5f5 (Fundo, contraste)
- **Cinza Escuro:** #333333 (Texto)
- **Dourado:** #b8860b (Acentos, elegância)

### Tipografia:
- **Headlines:** Fonte serif clássica (Georgia, Playfair Display)
- **Body Text:** Fonte sans-serif limpa (Open Sans, Roboto)
- **Tamanhos responsivos para leitura em qualquer tela**

### Elementos de Design:
- Imagens com bordas suaves e sombras naturais
- Ícones temáticos para alimentos/localização
- Separadores decorativos com motivo interior/rural
- Animações suaves (hover, scroll reveal)
- Transparências e sobreposições para texto sobre imagens

### Responsividade:
- **Mobile First:** Desenvolver com foco em mobile primeiro
- **Breakpoints:**
  - Mobile: até 768px
  - Tablet: 768px a 1024px
  - Desktop: acima de 1024px
- **Menu Mobile:** Hamburger menu responsivo
- **Touch-friendly:** Botões com tamanho mínimo de 44x44px
- **Imagens otimizadas:** Diferentes resoluções para cada dispositivo

## FLUXOS DE USUÁRIO

### Fluxo 1 - Visualizar Cardápio e Fazer Pedido:
1. Usuário acessa site → HOME
2. Clica em "VER CARDÁPIO"
3. Visualiza produtos com filtros
4. Adiciona itens ao carrinho
5. Clica em "Finalizar Pedido"
6. Preenche formulário de dados
7. Confirma e envia via WhatsApp
8. Recebe confirmação

### Fluxo 2 - Fazer Reserva:
1. Usuário acessa site → HOME
2. Clica em "FAZER RESERVA"
3. Preenche formulário com dados pessoais
4. Seleciona data e horário
5. Adiciona quantidade de pessoas e observações
6. Confirma e envia via WhatsApp
7. Restaurante confirma disponibilidade

### Fluxo 3 - Conhecer o Restaurante:
1. Usuário acessa HOME
2. Lê sobre o restaurante
3. Clica em "SOBRE" para mais informações
4. Visualiza galeria completa
5. Consulta dados de contato
6. Localiza no mapa
